## ✦ Featured projects

### Colorly

A playful color palette generator for creating harmonious color combinations
based on different moods or a starting color.

`HTML` · `CSS` · `JavaScript` · `Vite`

### Taskly

A task management app focused on making everyday organization simple and
intuitive, with features for planning, saved lists, finished days, themes,
and more.

`React` · `JavaScript` · `CSS` · `Vite`

> Taskly is currently paused while I focus on other projects.

### Dear Pages

A personal reading tracker for discovering books, organizing a library,
tracking reading statuses, creating collections, and keeping personal
ratings, reviews, and notes.

`React` · `JavaScript` · `Tailwind CSS` · `Vite` · `Firebase`

> Dear Pages is currently a work in progress.

## ✦ About the portfolio

The portfolio was designed and developed from scratch with a focus on
combining front-end development with the creative side of web design.

Some of the things I explored while building it include:

- responsive layouts
- reusable React components
- routing and project detail pages
- scroll and interface animations
- interactive UI details
- form handling
- image and asset optimization

I'm still learning and improving with every project, so this portfolio will
continue to grow alongside me ♡
